# Design Philosophy

This document explains the guiding principles, tradeoffs, and decisions behind the portfolio.  
Audience: Hiring managers, designers, UX leaders.

## Core Principles

1. **Clarity over cleverness:**  
   Make content legible, memorable, and understandable first.

2. **Constraints as design inputs:**  
   Technical debt, timelines, and legacy patterns shape solutions.

3. **Systems matter more than screens:**  
   Focus on scalable patterns rather than one-off UI moments.

4. **Accessibility is baseline quality:**  
   Not a checklist, but a core expectation.

## Key Design Decisions

- **Train Station Metaphor:** Provides cohesive narrative, memorable, visually consistent.
- **Centralized Case Study Data:** One template, typed schema for maintainability.
- **URL-driven state:** Shareable links and deep linking to stops.
- **Lazy loading:** Performance as a feature; fast mobile-first UX.

## Lessons Learned

- Learning to leverage AI has been awesome - look what I can build!
- Train metaphor is memorable.
- Data-driven architecture simplifies updates.
- Performance optimizations pay off.
- Considering accessibility earlier makes it easier to continue doing so.
